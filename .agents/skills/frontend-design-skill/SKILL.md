# Frontend Design Skill

## Guidelines & Architecture
1. **Modular Component Architecture**: Keep components small, focused, and single-purpose.
2. **Clean Styling Tokens**: Use CSS custom properties or Tailwind utility tokens. Avoid hardcoded inline style objects.
3. **Performance First**: Lazy load dynamic components with `next/dynamic` and wrap heavy calculations in `useMemo`.
4. **Accessible Semantics**: Use standard HTML5 elements (`main`, `nav`, `header`, `section`, `button`) with proper `aria-` labels.
