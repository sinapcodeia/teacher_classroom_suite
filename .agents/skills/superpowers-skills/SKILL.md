# Superpowers Skills

## Guidelines & Principles
1. **Empirical Diagnostics**: Inspect exact error logs before diagnosing runtime failures.
2. **Defensive Programming**: Wrap async calls in robust error boundaries and fallback handlers.
3. **Zero-Downtime Refactoring**: Verify changes with static checks and end-to-end build verification.
4. **Autonomous Resolution**: Identify and eliminate circular dependencies, deadlocks, and race conditions without manual intervention.
