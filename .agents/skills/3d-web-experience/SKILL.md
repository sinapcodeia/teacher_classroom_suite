# 3D Web Experience Skill

## Guidelines & Principles
1. **Spatial Depth**: Use CSS `perspective`, `transform-style: preserve-3d`, and subtle 3D tilt effects on cards.
2. **Fluid Canvas Effects**: Integrate lightweight canvas particle systems or Three.js scenes for landing backgrounds.
3. **Lighting & Glow**: Use radial gradient ambient lights and subtle glow effects (`box-shadow: 0 0 40px rgba(...)`).
4. **Hardware Acceleration**: Always use `transform: translate3d(...)` or `will-change` to leverage GPU rendering.
