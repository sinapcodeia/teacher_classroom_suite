# UI/UX Designer Skill

## Guidelines & Principles
1. **Visual Hierarchy**: Use scale, weight, and subtle opacity to guide user focus naturally.
2. **Glassmorphism & Depth**: Combine soft shadows, blurred backdrops (`backdrop-blur-md`), and thin subtle borders.
3. **Tactile Feedback**: Add smooth hover scaling (`hover:scale-[1.02]`) and active click feedback (`active:scale-95`).
4. **Delightful Micro-animations**: Use skeleton loaders, state transitions, and interactive badges.
