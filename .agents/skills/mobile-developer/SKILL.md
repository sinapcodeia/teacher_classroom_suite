# Mobile Developer Skill

## Guidelines & Principles
1. **Touch Targets**: Minimum hit area of 44x44px for buttons and interactive controls.
2. **Mobile-First Layouts**: Use responsive grid/flex layouts (`grid-cols-1 md:grid-cols-3`) with adaptive font sizing.
3. **Offline Backup**: Always save transient input state to `localStorage` before network requests.
4. **Touch Ergonomics**: Position primary action buttons within comfortable thumb reach on mobile screens.
