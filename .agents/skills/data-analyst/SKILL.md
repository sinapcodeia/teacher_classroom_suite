# Data Analyst Skill

## Guidelines & Principles
1. **Accurate Statistical Models**: Compute weighted averages, percentage distributions, and trend metrics using pure mathematical functions.
2. **Visual Analytics**: Use dynamic charts (e.g. Recharts, ApexCharts) with accessible color scales to convey analytical insights.
3. **Data Integrity**: Filter out invalid or missing null values before computing averages or aggregation ratios.
4. **Actionable Insights**: Highlight key performance indicators (KPIs), anomalies, and summary cards prominently.
