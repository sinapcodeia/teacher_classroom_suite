# Docs Generator Skill

## Guidelines & Principles
1. **Clear Markdown Structure**: Use GitHub Flavored Markdown with callout alerts (`> [!NOTE]`, `> [!TIP]`).
2. **Clickable File Links**: Include absolute `file:///` links to modified files and symbols.
3. **Structured Tables & Diagrams**: Use GFM tables and Mermaid diagrams for architectural workflows.
4. **Concise Summary**: Keep documentation actionable, accurate, and easy to read.
